# Contributing to the Commerce Comparison

We welcome contributions! To keep the data clean, please follow these rules:

### Adding a New Platform
To add a platform (e.g., BigCommerce, Commercetools):
1. Use the **45+ criteria** defined in the main README.
2. Provide a source for pricing or technical specs where possible.
3. Ensure the platform fits the "Commerce Platform" category.

### Editing Existing Data
If you notice an error in the Shopify, Crystallize, or Norce data:
1. Fork this repository.
2. Edit `data/comparison.csv`.
3. Submit a Pull Request with a brief note on what changed (e.g., "Updated Shopify's AI capabilities").
